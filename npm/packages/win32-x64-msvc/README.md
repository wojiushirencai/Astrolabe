This package ships the native `astrolabe.exe` binary for **win32-x64-msvc**.

It is an `optionalDependency` of the [`astrolabe`](https://www.npmjs.com/package/astrolabe) wrapper. You should not install it directly unless you are rebuilding a cross-platform lockfile.

The executable bit is declared via the `bin` field. There is no `postinstall` script.
