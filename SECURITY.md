# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |

Only the latest released version on GitHub receives security updates.

## Reporting a Vulnerability

**Do NOT open a public issue for security vulnerabilities.**

To report a security vulnerability, please use **GitHub's private vulnerability reporting**:

1. Go to [Security Advisories](https://github.com/wojiushirencai/Astrolabe/security/advisories/new)
2. Click "Report a vulnerability"
3. Fill in the details of the vulnerability

This ensures the report remains confidential until a fix is available.

### What to Expect

- We will acknowledge your report within a few days when possible.
- We will work with you to understand and validate the issue.
- Once confirmed, we will develop a fix and coordinate disclosure timing with you.

### Coordinated Disclosure

We prefer coordinated disclosure. Please allow us reasonable time to address the vulnerability before any public disclosure.

### No Email Contact

This project does not have a public security email. Please use GitHub Security Advisories exclusively for reporting vulnerabilities.

## Thank You

We appreciate security researchers who take the time to report vulnerabilities responsibly. Your efforts help keep Astrolabe and its users safe.
